# 🧠Desafio Persistência de Dados

## Esse projeto foi desenvolvido como forma de fixação e teste de conteúdos aprendidos durante o curso.

### O desafio apresentado no projeto é criar um aplicação que gravasse algumas informações de artistas como o nome, o tipo de artista (Solo, Dupla ou Grupo), e suas músicas, e que esses dados fossem persistidos.

## 📋Requisitos apresentados para o projeto
- Criar as entidades de Artista e Musica;
- Implementar o Enum para definir o tipo de artista;
- Criar a classe pricial de menu com as opções desejadas;
> Cadastrar artista, cadastrar música, pesquisar música por artista.
- Executar a aplicação através do CommandLine;
- As músicas só podem ser salvas no banco caso o Artista já tenha sido cadastrado previamente;
- Fazer integração com API de uma IA para buscar informações sobre um artista.

## 🚀Funcionalidades adicionadas fora das requisições mínimas
- Listar artistas cadastrados
- Listar músicas cadastradas
- Busca música por nome

## 🛠️Tecnologias Utilizadas
- Spring Data JPA
- PostgreSQL
- Java 21
- Springboot

## 📖Objetivos
Este projeto não possui fins comerciais, foi desenvolvido para praticar:
- Modelagem de classes
- Relacionamentos utilizando Spring Data JPA
- Persistência de dados
- Derived Queries e JPQL
- Integração com API's de IA
